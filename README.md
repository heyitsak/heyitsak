### ✦ About & Engineering Philosophy

I am a software engineer and builder focused on **human software craftsmanship**, **resilient backend architectures**, and **zero-bloat web standards**.

I believe software should be fast by default, accessible to everyone, and architected with intentional simplicity:

- 🏗 **Clean Code & Architecture:** Preferring clarity and separation of concerns over unnecessary abstraction layers.
- ⚡ **Performance Obsessed:** Dedicated to 100/100 Lighthouse audits, zero layout shifts, and sub-millisecond response latency.
- 🎨 **Editorial Aesthetics:** Melding meticulous typography, thoughtful color spaces (OKLCH), and tactile user feedback.
- 🔭 **Currently Building:** High-performance web tools, interactive visualization engines, and full-stack service portals.
